Section 1

Scalars, Vectors, Matrices & Tensors

The full ladder. Items 1.1–1.14 recap your existing notes; 1.15–1.22 are new.

1.1

Scalar

A scalar is a single number. Not a list, not a grid.

5    −2    0.75    π

Scalars are what you multiply vectors by. They are the simplest rung of the ladder that ends at tensors in 1.22.

1.2

Vector and components

A vector is an ordered list of numbers. Each number is a component.

v =34    v₁ = 3    v₂ = 4    v ∈ R²
x =2−15    x₁ = 2   x₂ = −1   x₃ = 5    x ∈ R³

Order matters. [3,4] and [4,3] are different vectors.

1.3

Vector dimension

The dimension of a vector is how many components it has.

5 → 1D    R¹
52 → 2D    R²
527 → 3D    R³
5271 → 4D    R⁴

There is no limit. Word embeddings live in R⁷⁶⁸ or higher — you cannot draw them, but every rule on this page still applies.

Careful

This is the dimension of a vector. Item 1.17 defines the dimension of a space, which is a different count. Do not merge them.

1.4

Vector addition

Add component by component.

23 +45 =2+43+5 =68
Rule
Dimensions must match.

[2,3] + [4,5,6] is undefined. A 2D and a 3D vector cannot be added.

Geometrically: place the tail of the second vector at the head of the first. The sum runs from the original start to the final end.

1.5

Vector subtraction

Same rule, component by component.

83−2 −514 =32−6

Subtraction is addition of the negative: a − b = a + (−b). The vector b − a points from a to b, which is why item 4.2 uses it for distance.

1.6

Scalar multiplication

Multiply every component by the scalar.

323 =69     −234 =−6−8
Rule
kv = [kv₁, kv₂, …, kvₙ]

A positive scalar changes length only. A negative scalar also reverses direction.

1.7

Magnitude / length

Pythagoras, extended to any number of components.

v =34    ‖v‖ = √(3² + 4²) = √25 = 5
Rule
‖v‖ = √(v₁² + v₂² + … + vₙ²)

Also called the L2 norm. Item 4.4 and 4.5 give two other ways to measure length.

1.8

Normalisation

Divide a vector by its own length to get a unit vector — same direction, length exactly 1.

Rule
v̂ = v / ‖v‖
v =122   ‖v‖ = √(1+4+4) = 3

v̂ = ⅓122 =1/32/32/3

check: ‖v̂‖ = √(1/9 + 4/9 + 4/9) = √(9/9) = 1  ✓

Every non-zero vector normalises to length 1. Normalisation strips away magnitude and keeps only direction, which is exactly what cosine similarity needs (item 3.4).

1.9

Dot product

Multiply matching components, then add. The result is a scalar, not a vector.

23 ·45 = (2×4) + (3×5) = 8 + 15 = 23
Rule
a · b = a₁b₁ + a₂b₂ + … + aₙbₙ

This one operation is the engine of nearly everything later: angles, projection, matrix multiplication, and attention scores all reduce to dot products.

1.10

Relationship between dot product and angle

Rule
a · b = ‖a‖ ‖b‖ cosθ

so   cosθ = (a · b) / (‖a‖ ‖b‖)
a =34   b =43

a · b = 12 + 12 = 24
‖a‖ = 5    ‖b‖ = 5

cosθ = 24 / 25 = 0.96

1.11

Orthogonal vectors

Orthogonal means perpendicular. The test is a single number.

Rule
a ⊥ b  ⇔  a · b = 0
a =12   b =2−1

a · b = (1×2) + (2×−1) = 2 − 2 = 0  →  a ⊥ b

No trigonometry needed. If the dot product vanishes, the angle is 90°, because cos 90° = 0 in the formula above.

1.12

Cosine similarity

Use cosθ itself as a similarity score between two vectors.

Rule
−1 ≤ cosθ ≤ 1

  1 → same direction
  0 → perpendicular, unrelated
−1 → opposite direction

Because the formula divides by both lengths, cosine similarity measures direction only and ignores magnitude. Two vectors pointing the same way score 1 whether they are short or long.

Why this is the standard in ML

Embedding vectors encode meaning in their direction. A long vector is not "more" of a word, so magnitude is noise. Cosine similarity throws it away.

1.13

Distance between vectors

Subtract, then take the length of the difference.

Rule
d(a, b) = ‖b − a‖
a =12   b =46

b − a =34
‖b − a‖ = √(9 + 16) = 5

Note d(a,b) = d(b,a): reversing the subtraction flips the sign of every component, which squaring undoes.

1.14

Linear combinations

Scale some vectors, then add them.

a =12   b =31

2a =24    3b =93

2a + 3b =117
Rule
c₁a + c₂b + … + cₙvₙ

This is the single most reused idea in the whole workshop. Span (5.1) is the set of all linear combinations. Matrix × vector (2.7) is a linear combination. Attention's output (9.10) is a linear combination.

1.15

What a vector space is

A set of objects with two operations defined on it, where results always stay inside the set: addition, and multiplication by a scalar.

Addition
1. v + w = w + v
2. (u + v) + w = u + (v + w)
3. there is a zero vector 0, with v + 0 = v
4. every v has an inverse −v, with v + (−v) = 0

Multiplication
5. 1v = v
6. (αβ)v = α(βv)

Distributive
7. α(u + v) = αu + αv
8. (α + β)v = αv + βv
The useful summary
You can add two vectors.
You can multiply a vector by a number.
You cannot multiply two vectors.
You cannot add a number to a vector.

Other things that satisfy all 8 rules, and so are vector spaces: all m×n matrices, all polynomials of degree at most n, the real numbers themselves.

1.16

Rⁿ

The specific vector space you have been working in all along: all columns of n real numbers.

R² = allv₁v₂    R³ = allv₁v₂v₃    Rⁿ = all n-component columns

Addition and scalar multiplication work entry by entry, exactly as in 1.4 and 1.6. Checking the 8 axioms against those definitions is straightforward, which is why Rⁿ is the standard example of a vector space.

1.17

Dimension of a vector space

Rule
dim V = the number of vectors in a basis of V

Every basis of the same space has the same number of vectors, which is what makes this a well-defined count.

Not the same as 1.3

A vector's dimension is its component count. A space's dimension is its basis size. They often differ.

L = span{12}  — a line through the origin in R²

basis of L has 1 vector → dim L = 1
but every vector on L has 2 components
The picture
A 1-dimensional space
made of 2-component vectors.

1.18

Basis

A minimal set of vectors that can build the whole space.

Rule
A basis is a set that
1. spans the space, and
2. is linearly independent.
Standard basis of R²
e₁ =10   e₂ =01

3e₁ + 5e₂ =35   any vector, uniquely
Standard basis of R³
e₁ =100 e₂ =010 e₃ =001

4e₁ + 7e₂ + 2e₃ =472

A basis is a coordinate system. The coefficients are the coordinates.

1.19

Linear independence

No vector in the set can be built from the others. Nothing is redundant.

Independent
a =10 b =01   no scalar c gives ca = b

Dependent
a =12 b =24   b = 2a
Consequence
2 independent vectors in R² → span the whole plane
2 dependent vectors in R² → span only a line
1.20

Relationship between basis, span, independence, and dimension

All four are one idea seen from different angles. Worked in R², dimension 2:

[1,0] [0,1]yesall of R²2yes

fewer than n vectors → can never span
more than n vectors → must be dependent

In a space of dimension m:
any m independent vectors form a basis
any m vectors that span form a basis

So once you know the dimension, you check only one condition.

1.21

Matrices

The next rung: a rectangular grid of numbers, m rows by n columns. Section 2 covers them in full; here is the placement.

A =123456    2 × 3

A column vector in Rⁿ is an n × 1 matrix, so everything in items 1.2–1.14 was already a matrix one column wide.

1.22

Tensors

A tensor is a multi-dimensional array. Its order is how many indices you need to reach one element.

order 0 → scalar     5
order 1 → vector     v[i]
order 2 → matrix     A[i][j]
order 3 → tensor     T[i][j][k]
order n → tensor     n indices
one colour image → height × width × channels → order 3
a batch of images → batch × H × W × C → order 4
transformer input → batch × tokens × dmodel → order 3
Two different meanings — do not mix them

In machine learning a tensor is an n-dimensional array, as above. In pure mathematics a tensor is a multilinear function, a genuinely different and much heavier idea. LADW chapter 8 teaches the second one. For this workshop you want the first. Do not read that chapter for this item.

What a matrix is

Rule

Rows first. Always.

Identical to vector addition in 1.4, including the size restriction.

2.11

Dimension reduction: 4D → 3D

Needs 4 columns and 3 rows, so a 3 × 4 matrix.

A =100001000010

A1234 =123   the 4th component is gone
A mixing example: 110000111001 1234 =375
Rule
Reducing dimension destroys information.
You cannot undo it.

2.12

Dimension increase: 4D → 6D

Needs 4 columns and 6 rows, so a 6 × 4 matrix.

A is 6 × 4   (identity on top, two zero rows below)

Rule

Raising dimension cannot create information.

Dot Product, Angle & Similarity

The checklist lists these again as a consolidation. Compact recap with the formulas together in one place — full treatment is at 1.9–1.12.

3.1

Dot product

a · b = a₁b₁ + a₂b₂ + … + aₙbₙ

23 ·45 = 23

Returns a scalar. See 1.9.

3.2

Angle relationship

a · b = ‖a‖ ‖b‖ cosθ

cosθ = (a · b) / (‖a‖ ‖b‖)

See 1.10 for the worked example.

3.3

Orthogonality

a ⊥ b  ⇔  a · b = 0

See 1.11. Section 6 builds projection on top of this.

3.4

Cosine similarity

−1 ≤ cosθ ≤ 1
  1 → same direction    0 → perpendicular    −1 → opposite
The consolidation worth writing
dot product  →  a raw number
cosine similarity → that number,
  normalised to ignore length

Dividing by both magnitudes is what turns an unbounded score into a bounded, comparable one. That is the entire difference between the two.

Section 4

Norms, Distance & Normalisation

4.1–4.3 recap; 4.4–4.6 add the two other norms and the comparison.

4.1

L2 norm / Euclidean magnitude

‖v‖₂ = √(v₁² + … + vₙ²)

‖34‖₂ = 5

See 1.7. Called L2 because of the exponent 2.

4.2

Distance between vectors

d(a, b) = ‖b − a‖

See 1.13. Any norm gives a distance this way, so there is also an L1 distance and an L∞ distance.

4.3

Normalisation

v̂ = v / ‖v‖    ‖v̂‖ = 1

See 1.8.

4.4

L1 norm

Add the absolute values. No squaring, no square root.

‖v‖₁ = |v₁| + |v₂| + … + |vₙ|

v =3−4   ‖v‖₁ = 3 + 4 = 7

Called the taxicab or Manhattan norm: the distance you walk on a street grid, never cutting diagonally.

Why anyone cares

Minimising with L1 gives a sparse answer — mostly zero components. Minimising with L2 gives many small non-zero numbers instead, because squaring a small number barely penalises it. This is the basis of L1 regularisation and compressed sensing.

4.5

L∞ norm

Just the largest absolute component. Everything else is ignored.

‖v‖∞ = max |vᵢ|

v =3−4   ‖v‖∞ = max(3, 4) = 4

All three norms are one formula, the p-norm:

‖v‖p = ( ∑ |vᵢ|p )1/p

p = 1 → L1    p = 2 → L2    p → ∞ → L∞
Every norm obeys 3 axioms
1. ‖v‖ ≥ 0, and = 0 only if v = 0
2. ‖v + w‖ ≤ ‖v‖ + ‖w‖
3. ‖αv‖ = |α| ‖v‖

4.6

Compare L1 vs L2 vs L∞

v =3−4

‖v‖₁ = 3 + 4 = 7
‖v‖₂ = √25 = 5
‖v‖∞ = 4
Rule
‖v‖∞ ≤ ‖v‖₂ ≤ ‖v‖₁

4  ≤  5  ≤  7

Always true, for every vector. Larger p gives a smaller number.

The clearest way to see the difference is the shape of the unit ball, the set of all v with ‖v‖ = 1. Draw all three on one set of axes:

NormUnit ball in R²Corners at
L1diamond(±1, 0), (0, ±1)
L2circlenone — smooth
L∞square(±1, ±1)
The picture
diamond ⊂ circle ⊂ square

Same inequality as above, drawn. Smallest ball, largest norm.

Why the diamond gives sparsity

The L1 diamond has its corners on the axes. Corners are where an optimiser tends to land, and a point on an axis has zero in the other coordinate. The circle has no corners, so nothing pulls the answer onto an axis. That is the geometric reason L1 produces sparse answers and L2 does not.

5.5

LoRA as an example

Fine-tuning a large model means changing a big weight matrix W. LoRA's bet is that the change needed is low rank, even though W itself is not.

Rule
W = W₀ + ΔW = W₀ + BA

W₀ is d × k   frozen
B is d × r   trained
A is r × k   trained
r ≪ min(d, k)

BA is (d×r)(r×k) = d×k, the right shape to add to W₀ — the size rule from 2.9. And BA can have rank at most r.

Parameter count   d = k = 768, r = 8

full W  →  768 × 768 = 589,824
B and A → 8 × (768 + 768) = 12,288

12,288 / 589,824 = 2.1% of the parameters
The saving
d × k  →  r(d + k)
Why it starts as a no-op

B is initialised to all zeros and A to random values, so BA = 0 at step one and the model behaves exactly as before. The update grows from nothing.

Orthogonality and Projection

Given a vector and a direction, how much of the vector lies along it.

6.1

Orthogonality

a ⊥ b  ⇔  a · b = 0

12 ·2−1 = 2 − 2 = 0

See 1.11. Everything below is built on this one test.

6.2

Projection

Split a vector into two pieces: the part along a direction, and the part perpendicular to it.

b = p + e

p = the part along a  (the projection)
e = b − p  (the perpendicular remainder)

defining condition:   e · a = 0
Rule
Every vector splits uniquely into
a piece along a
plus a piece perpendicular to a.
Simplest case — onto the x-axis

a =10   b =34  →  p =30   e =04

check e · a = 0  ✓
6.3

Projection formula

Derive it in three lines. We want p = ca with b − ca perpendicular to a.

(b − ca) · a = 0
b·a − c(a·a) = 0
c = (b·a) / (a·a)
Rule
              (b · a)
proja(b) = ———— a
              (a · a)
a =11   b =31

b · a = 4    a · a = 2    c = 2

p = 211 =22   e =1−1

check e · a = 1 − 1 = 0  ✓
The shortcut

If a is a unit vector then a·a = 1 and the formula collapses to p = (b·a)a. This is why normalisation (1.8) keeps reappearing.

6.5

Why projection matters

Best approximation theorem
‖b − Pb‖ ≤ ‖b − u‖
for every u in the subspace

The projection is the closest point in the subspace to b. Nothing in that subspace is nearer.

That single fact is why projection is everywhere:

  • Least squares. When Ax = b has no solution, project b onto the column space and solve that instead. Best possible fit.
  • Dimension reduction. Projecting onto a smaller subspace loses the least information possible.
  • Cosine similarity. Item 3.4 is projection with both vectors normalised.
The trade-off, exactly
‖p‖² + ‖e‖² = ‖b‖²

Pythagoras, since p ⊥ e. Check with 6.3: 8 + 2 = 10 ✓. ‖b‖ is fixed by the data, so maximising what you keep is the same as minimising what you discard.

6.6

Introduction to PCA

Take a cloud of data points and project them all onto one line through the origin. Different lines give different pictures: some spread the points out, some squash them together.

The idea in one line
PCA is the search for the line
that spreads the data out the most.

By the Pythagoras identity in 6.5, that is the same as the line that loses the least when you throw away the perpendicular part. Maximum spread kept and minimum error discarded are the same problem.

What is still missing

How do you actually find that line? You cannot try them all. The answer turns out to be an eigenvector, which is why section 7 comes next. Item 7.7 completes this.

Section 7

Eigenvalues and Eigenvectors

The directions a matrix does not turn. Square matrices only.

7.1

Eigenvector

A non-zero vector whose direction is unchanged by the matrix. A normally turns a vector; an eigenvector it only stretches.

Two conditions

Only square matrices have eigenvectors, and an eigenvector is never the zero vector.

7.2

Eigenvalue

The scalar that says how much the eigenvector was stretched. Written λ. Unlike eigenvectors, λ is allowed to be zero.

7.3

Av = λv

The defining equation
A v = λ v    (v ≠ 0)

Left side: a matrix multiplication. Right side: a scalar multiplication. The whole content of the equation is that these two very different operations agree.

7.4

Simple numerical example

Checking a candidate is easy: multiply and see if you get a multiple back.

A =22−48   v =11   w =21

Av =44 = 4v  →  eigenvector, λ = 4  ✓

Aw =60   not a multiple of w  →  not an eigenvector

Geometric meaning

Rule
An eigenvector is a direction
the matrix does not rotate.

λ = 0 means A crushes that direction to nothing, so it lies in the null space. A square matrix has a zero eigenvalue exactly when it is not full rank (5.3).

7.7

PCA in depth

Item 6.6 asked for the line that spreads the data out most. Here is the answer.

The algorithm
1. centre the data   xᵢ − x̄
2. build the covariance matrix Σ
3. find the eigenvectors of Σ
4. sort by eigenvalue, largest first
5. keep the top p, discard the rest
    1
Σ = —  ∑ (xᵢ − x̄)(xᵢ − x̄)T    x̄ = mean
    m

Σ is n × n and symmetric
Rule
principal components = eigenvectors of Σ

eigenvalue = variance along that direction
larger eigenvalue = more important

Why eigenvectors, in one line: maximising the spread uᵀΣu subject to uᵀu = 1 gives, via a Lagrange multiplier, exactly Σu = λu. The direction of maximum variance is an eigenvector.

Why Σ being symmetric matters

From 7.6, a symmetric matrix has orthogonal eigenvectors. So the principal components come out perpendicular automatically. They form a basis (1.18) — a new set of axes for the data.

n original dimensions → n eigenvectors
keep the top p → data now p-dimensional

information lost = the discarded eigenvalues
small eigenvalues → little lost

Section 8

SVD & Low-Rank Approximation

Eigenvectors need a square matrix. SVD works on any matrix at all, and it is where rank, projection and eigenvalues all meet.

8.1

What SVD is

A factorisation that splits any matrix into three simple pieces: a rotation, a stretch, and another rotation.

Rule
Every m × n matrix can be written
as a product of three matrices.

Square or not. No exceptions.

Compare eigenvectors, which only exist for square matrices and can fail even then. SVD always works, which is why it is the workhorse of applied linear algebra.

8.2

A = UΣVT

The equation
A = U Σ VT
A  is m × n
U  is m × m   orthogonal
Σ  is m × n   diagonal, non-negative
VT is n × n   orthogonal

Check the shapes with the size rule from 2.9:

(m×m)(m×n)(n×n) = m×n  ✓

Orthogonal means the columns are mutually perpendicular unit vectors, so UᵀU = I. Orthogonal matrices preserve lengths and angles — they rotate without distorting.

Princeton NEU560 lecture 4 · LADW PDF p181
8.3

Meaning of U, Σ, and VT

Where the pieces come from
columns of U = eigenvectors of AAT
columns of V = eigenvectors of ATA
σᵢ = √λᵢ

ATA and AAT are square and symmetric even when A is neither, which is exactly why SVD always exists. Section 7 gave you eigenvectors of symmetric matrices; this reuses that.

PieceHoldsDoes
VTinput directionsrotates the input
Σsingular valuesstretches each axis
Uoutput directionsrotates the result
8.4

Step 1 — rotate / change basis

Read A = UΣVᵀ right to left, because by 2.9 the rightmost transformation happens first.

VT acts first

it rotates the input into a new set of axes
lengths and angles unchanged — nothing is distorted

This is a change of basis (1.18): the same vectors, described in better-chosen coordinates. The point of the new coordinates is that the stretching in step 2 becomes axis-aligned and therefore simple.

8.5

Step 2 — scale

Σ acts second

it multiplies axis 1 by σ₁
           axis 2 by σ₂
           and so on
All the distortion lives here
unit circle  →  ellipse

with half-axes σ₁, σ₂, …

Because U and VT are pure rotations, Σ is the only part of A that changes shape, stretches, or flattens. Everything a matrix does to size and volume is in these numbers.

8.6

Step 3 — rotate / change basis again

U acts last

it rotates the ellipse into its final position
shape unchanged, orientation changed
The whole of SVD, in three words
rotate  →  scale  →  rotate

That is every matrix, without exception.

8.7

Singular values

σ₁ ≥ σ₂ ≥ … ≥ σᵣ > 0

always sorted, largest first
always ≥ 0, unlike eigenvalues
Cleanest definition of rank
rank A = the number of
non-zero singular values

Same number as 5.2, but now you can also see how nearly zero the others are, which counting cannot tell you.

Why this is the practical definition

Counting independent columns gives a yes/no answer. Singular values give a ranked list. If σ₄ = 0.0001 the matrix is technically rank 4 but behaves like rank 3. Real data is always like this, and only the SVD reveals it.

SVD rewritten as a sum of rank-1 pieces — the form everything below uses:

Rule
A = σ₁u₁v₁T + σ₂u₂v₂T + … + σᵣuᵣvᵣT

Each term is a column times a row, which by 5.4 is a rank-1 matrix. So every matrix is a weighted stack of rank-1 layers, heaviest first.

Princeton NEU560 lecture 4 §1 and §4
8.8

Low-rank approximation

Keep the first k layers of the stack, throw the rest away.

Ak = σ₁u₁v₁T + … + σkukvkT
Eckart-Young theorem
If B has rank k, then

‖A − B‖ ≥ ‖A − Ak‖

No rank-k matrix anywhere is closer to A than Ak. Truncating the SVD is not just a good approximation, it is provably the best one.

Strang's example

A = diag(4, 3, 2, 1)   rank 4

best rank 2 → A₂ = diag(4, 3, 0, 0)
keep the two largest, zero the rest
Item 6.5 pays off here

Eckart-Young is the best-approximation theorem again, one level up. There it was the closest point in a subspace; here the closest matrix of a given rank. Same idea.

MIT 18.065 lecture 7 (Strang) · Princeton NEU560 §4
8.9

Connection to compression and information

The chain
rank  →  how much information
singular values → how much each direction carries
truncation  →  keep the most, store the least

Storing a full m × n matrix costs mn numbers. Storing a rank-k approximation costs only the pieces it needs:

k columns of U  →  mk
k singular values → k
k columns of V  →  nk
——————————
total  →  k(m + n + 1)

This beats mn whenever k is small, which is the whole game. And the PCA link closes here: running PCA on centred data is the same computation as taking the SVD of the data matrix. The principal components are the right singular vectors; the variances are the singular values squared.

8.10

Pixel example

A greyscale photo is a matrix: one number per pixel.

1000 × 1000 image  →  1,000,000 numbers

rank-k storage → k(1000 + 1000 + 1) = 2001k

Real images have singular values
that fall off fast.

A few layers carry nearly all the picture.
One-sentence summary of section 8

Rank is how much independent information is present, singular values measure how much each direction carries, truncating the SVD keeps the most information for the least storage, and Eckart-Young proves nothing does better.

Bringing Everything Together with Attention

Every item so far feeds into this. Built one factor at a time, in the order the equation is computed.

9.1

Why transformers operate on vectors, matrices and tensors

a word  →  a vector in Rd  (an embedding)
a sentence of n words → an n × d matrix X
a batch of sentences → an order-3 tensor
Rule
word → vector
sentence → matrix
batch → tensor

Exactly the ladder from 1.22.

Two reasons this is the right representation:

  • Meaning becomes geometry. Similar words sit close together, and closeness is the dot product from 1.9. Cosine similarity (3.4) is already the core operation.
  • Everything happens at once. Stacking words as rows means one matrix multiplication processes the whole sentence in parallel, not word by word.
Your notes already end here

Item 1.3 finished on v ∈ R⁷⁶⁸. That is exactly a word embedding. Everything since has been machinery for operating on it.

9.2

Q, K, V

Each word produces three different vectors by multiplying its embedding by three learned weight matrices.

Rule
Q = X WQ   queries   what am I looking for
K = X WK   keys      what do I offer
V = X WV   values    what I pass on
X is n × d
WQ, WK, WV are d × dk

Q, K, V are each n × dk
The library analogy

query → the question you ask at the desk
key   → the label on each book's spine
value → what is actually inside the book

match your query against every key,
then collect the values that matched
Self-attention

Q, K and V all come from the same sentence X. Every word queries every other word in its own sentence, which is why it is called self-attention.

9.3

Query matrix

Q = X WQ    (n × d)(d × dk) = n × dk

row i of Q = qᵢ = the query vector for word i

Each row asks a question on behalf of one word: what kind of context am I looking for? WQ is learned, so the model discovers what questions are worth asking.

9.4

Key matrix

K = X WK    also n × dk

row j of K = k⫺ = the key vector for word j

Each row advertises what that word has to offer. A query and a key match when their dot product is large, which is why Q and K must share the same width dk.

9.5

Value matrix

V = X WV    n × dv

row j of V = v⫺ = the content word j contributes

Values carry the actual payload. Q and K decide how much to take from each word; V is what gets taken. This is why V can have a different width from Q and K.

9.6

QKT

We need the dot product of every query with every key. Item 1.9 handles one pair. This does all pairs at once.

Q KT → (n × dk)(dk × n) = n × n

entry (i, j) = qᵢ · k⫺
= how much word i should attend to word j
The result
an n × n score matrix
one number for every pair of words
Why this is expensive

Every word scores against every word, so cost grows with n². That is why context windows are costly and long-context models are hard.

9.7

Why the transpose is needed

The shape argument
Q is n × dk
K is n × dk

Q K  → (n×dk)(n×dk)  undefined
Q KT → (n×dk)(dk×n) = n × n  ✓
The answer in one sentence
Without the transpose the inner
dimensions do not match and the
multiplication does not exist.

The transpose turns K's rows into
columns so every query can meet
every key.

This is the size rule from 2.9 and the transpose from 2.6, doing real work. Nothing exotic is happening — it is bookkeeping that has to come out right.

9.8

Scaling by √dk

Why divide
As dk grows, dot products grow large.

Large inputs to softmax make it
saturate, and the gradients
become tiny.

Dividing by √dk keeps them
in a usable range.

Each score is a sum of dk products, so scores grow with dk. Dividing by √dk cancels that growth.

Worth being precise about

This is a numerical fix for training, not a mathematical necessity. The attention mechanism is well defined without it; it just trains badly.
